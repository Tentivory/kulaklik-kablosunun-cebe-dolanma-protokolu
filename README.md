# T.C. Kulaklık Kablosu Cebe Dolanma Protokolü Müdürlüğü

> Kablo düzgün durmaz. Çünkü düzgün durmak, protokol dışıdır.

Bu yazılım, kablolu kulaklığınızı cebe koyduğunuz anda oluşan **ulusal düğüm krizini** resmi evrak formatında belgelendirir.  
Düğümü **çözmez**. Düğümü **tanır**. Tanımak yeterlidir. Çözmek popülizmdir.

Patates yoktur. Kablo vardır. Kablo yeter.

## Bu proje neden var?

Çünkü her vatandaşın cebinde en az bir adet:

- kendi kendine düğümlenmiş,
- jakıyla evlenmiş,
- astara sığınmış,
- ve çözüldüğünde yeniden düğümlenen

bir kablo vardır. Bilim bunu açıklayamaz. Bürokrasi açıklar.

## Kurulum

Python 3 yeter. Başka bir şey istemeyiz. İstemek zaaftır.

```bash
python3 protokol.py
python3 protokol.py --cep "sağ pantolon cebi"
python3 protokol.py --adet 3
```

## Örnek çıktı

Program çalıştığında evrak numarası, düğüm sınıfı, dolanma katsayısı ve **kesin karar** basar.  
Karar genellikle şudur: *düğüm onaylandı, çözüm talebi reddedildi.*

## Düğüm sınıfları (resmi)

| Katsayı | Sınıf | Hukuki durum |
|--------:|-------|----------------|
| 1 | Tek Döngü Vatandaş Düğümü | Hafif ihlal |
| 2 | Çift Sarmal Bürokratik Düğüm | Normal işleyiş |
| 3 | Jak ile İttifak | Diplomatik kriz |
| 4 | Cep Astarına Sığınma | İltica dosyası |
| 5 | Gece Yarısı Çözülmezlik | Doğa olayı |
| 9 | Tam Bağımsızlık Düğümü | Müdahale yasak |

## Sık sorulan resmi sorular

**Kabloyu çözebilir miyim?**  
Hayır. Çözmek, tutanağı yok saymaktır.

**Bluetooth kullanabilir miyim?**  
Teknik olarak evet. Protokol açısından firardır.

**Bu komik mi?**  
Hayır. Bu müdürlüktür.
